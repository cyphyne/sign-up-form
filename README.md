# Sign-Up Form

A responsive sign-up form built with HTML, CSS, and JavaScript.

## Features
- Responsive design for desktop and mobile devices
- Custom form validation with JavaScript
- Individual error messages for individual inputs
- Password confirmation validation
- Terms and conditions validation
- Custom invalid-input styling
- Custom favicon and image asset

## Technologies
- HTML
- CSS
- JavaScript

This project was originally created as a form design exercise and was further enhanced with mobile responsiveness, more thorough JavaScript validation, and custom visual assets.
